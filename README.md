# Student Performance Analysis

## About the Project

This is a beginner-friendly data analysis project developed using Python. It analyzes student marks in 3 subjects
## Technologies Used

* Python
* Pandas
* Matplotlib
* Google Colab

## Features

* Calculates total and average marks.
* Identifies pass and fail results.
* Calculates the overall pass percentage.
* Identifies the subject with the lowest average score.
* Displays pie charts showing high-score and low-score distributions for each subject.

## Dataset

The project uses sample student marks for demonstration and learning purposes.

## Learning Outcomes

* Basic data analysis using Pandas.
* Working with DataFrames.
* Calculating averages and results.
* Creating visualizations using Matplotlib.

## How to Run

Open the `.ipynb` notebook in Google Colab and run the cells in order.
